QUEBRA-SENHA — duelo 1v1 online
================================

Arquivos: index.html, style.css, app.js, firebase-config.js

0) TREINAR SOZINHO
   Na tela inicial, clique em "Treinar sozinho contra o robô". Funciona sem Firebase.

1) TESTAR SEM CONFIGURAR NADA
   Abra o index.html por um servidor (ou pelo GitHub Pages) em DUAS abas do mesmo navegador.
   Sem Firebase, o jogo roda em "modo local" e só conecta abas do mesmo navegador.

2) JOGAR EM DOIS COMPUTADORES (Firebase, grátis)
   a. console.firebase.google.com > use um projeto que você já tem ou crie um.
   b. Build > Realtime Database > Criar banco.
   c. Aba "Regras", cole isto e publique:

      {
        "rules": {
          "quebrasenha": {
            "rooms": {
              "$code": { ".read": true, ".write": true }
            }
          }
        }
      }

   d. Configurações do projeto > Seus apps > Web (</>) > copie o objeto firebaseConfig
      (ele precisa ter o campo databaseURL).
   e. Cole no firebase-config.js no lugar de "null".
   f. Suba a pasta para o GitHub Pages.

3) COMO JOGAR
   - Um cria a sala e manda o código (ou o botão "Copiar link"). O outro entra com o código.
   - O dono da sala escolhe: tamanho da senha (8, 10 ou 12), tempo por jogada, quem começa e repetição.
   - Cada um cria a senha (letras e números) no próprio PC. A senha NÃO vai para o servidor durante a partida.
   - Verde = lugar certo. Laranja = existe em outro lugar. Vermelho = não existe (ou já contou todas as cópias).
   - Na vez do outro, você vê ao vivo o que ele está digitando.
   - Os dois precisam ficar com a página aberta até o fim.
   - Recarregou sem querer? Abra o mesmo link (?sala=CÓDIGO) que volta pra sala.

4) GRAVAÇÃO
   - Os cantos de baixo, dos dois lados do notebook, ficam livres para as câmeras.
   - Funciona melhor em 1920x1080 em tela cheia (F11).
